TOOLNEST COMPLETE FILES
========================
Files:
- index.html
- style.css
- script.js
- about.html
- README.txt

For HTML Viewer:
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in your HTML Viewer.

For GitHub Pages:
1. Upload ALL files to the repository root.
2. Make sure index.html is in the root.
3. Settings > Pages > Deploy from branch > main > /root > Save.

Note: QR Code Generator uses a public online QR service and therefore needs internet access.
