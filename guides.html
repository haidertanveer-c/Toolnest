How to count words and characters

A word count is usually the number of groups of text separated by whitespace. Character count measures the characters in the text, including spaces and punctuation. Different apps can use slightly different counting rules, so when a submission has a stated limit, use the rules provided by that platform.

For a quick browser-based count, open the Word Counter on ToolNest and paste your text.

What is JSON formatting?

JSON is a text format commonly used to represent structured data. Minified JSON can be difficult to read because everything is compressed onto a small number of lines. Pretty-printing adds indentation and line breaks so the structure is easier to inspect.

A formatter does not automatically make invalid JSON valid. If a parser reports an error, check quotation marks, commas, brackets and the names of properties.

How to calculate days between dates

To calculate the difference between two calendar dates, convert both dates to a common date representation and compare them. The result can be expressed as a whole number of days. Time zones and daylight-saving changes can affect calculations that use exact timestamps, which is why a date-only calculator is best for simple calendar differences.

How browser image resizing works

An image can be resized by drawing it onto an HTML canvas at a new width and height. The resulting canvas can then be exported as an image file. Changing dimensions can affect image quality, so keep the original file when quality matters.

Using a generated password safely

A password generator can create random-looking strings for accounts. Use a different password for each important account, and keep passwords in a reputable password manager when possible. Never share a password with someone who does not need it.

ToolNest's generator creates the password in the browser interface. This page does not ask you to submit or publish the generated password.
